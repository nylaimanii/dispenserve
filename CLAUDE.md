# Dispenserve

A free dispenser for college students: one item per person per day. A laptop camera does face matching in Python (`vision/`), and an Arduino Uno (`dispenser/`) drives a 9g servo that sweeps a slotted disc. Machines report anonymous counts to Tiger Data and Snowflake, write a public donor ledger to Solana devnet, get restock advice from Gemini, and speak fixed lines generated by ElevenLabs. Entered in Bloomberg's "Most Philanthropic Hack" plus the Tiger Data, DigitalOcean, Snowflake, Solana, Gemini and ElevenLabs prizes. The whole repo (including `ui/`) is one person's now.

## Layout

- `dispenser/dispenser.ino`: 9V into the barrel jack, servo on 5V, signal pin 9 (attached only during a sweep, 1°/10ms). HC-SR04 trig 3 / echo 4; green LED pin 6, red LED pin 7; watchdog. Serial 9600: `ready` on boot, `nosensor` if the sensor never echoes, `d` → sweep → `ok` (~4.9s), `x` → red LED 3s, unsolicited `near` / `away`.
- `vision/` (flat imports, run as `.venv/bin/python vision/<file>.py`):
  - `main.py`: the app. Camera loop, 3s hold (`HoldTracker`), `Dispenserve` (decision side effects, sleep/wake, voice, telemetry, ledger), `--no-camera` fake scans, every `--no-<name>` flag. Keys f/c/r/q.
  - `memory.py`: `MemoryStore` (vectors in RAM) and `decide()`. `state.py`: kiosk state (incl. `sleep`), daily and hourly counters.
  - `serial_link.py`: background reader thread; routes `ok` / `near` / `away` / `nosensor`; reconnects; `jammed` flag.
  - `server.py`: port 8000, `/state` `/stats` `/insights` `/metrics` `/set` `/flush-solana` (loopback only), serves `ui/` pages.
  - `telemetry.py` + `sinks/` (`base.py` queue/retry per sink, `tiger_sink.py`, `snowflake_sink.py`): `{machine_id, bay, event, ts}` fan-out.
  - `ledger.py`: Solana devnet memo transactions, built and signed by hand (ed25519 via `cryptography`); keypair/airdrop CLI.
  - `insights.py`: Gemini restock advice from aggregates, 10 min cache, rule-based fallback. `voice.py`: ElevenLabs clips cached in `vision/audio/`, macOS `say` fallback.
  - `liveness.py`, `metrics.py`, `tune.py`, `config.py`; hardware checks `test_serial.py`, `focus_test.py`, `face_test.py`.
- `cloud/schema.sql` (TimescaleDB), `cloud/snowflake_schema.sql`, `cloud/api/` (FastAPI: `/fleet` `/forecast` `/ledger` `/health`, `--fake`, Dockerfile), `.do/app.yaml`.
- `ui/kiosk.html` (sleep screen + scanner), `ui/dashboard.html` (machine, alerts, insight, fleet, ledger), `ui/mockserver.py`.
- `tests/`: `.venv/bin/pytest`, no hardware or keys needed. Keep it passing.
- Docs: `README.md`, `PRIVACY.md`, `DEVPOST.md`, `PRIZES.md`, `SETUP_KEYS.md`, `.env.example`.

## Privacy and matching rules

- Face vectors live in memory only. Never write them (or images, or landmarks) to disk: no files, databases, logs, caches, or pickles. Never send them anywhere.
- Entries are purged after 24 hours. Match threshold: cosine similarity 0.42 (strictly greater is a match).
- Fails open: any error during matching or liveness → dispense. (A lost camera reconnects; it does not dispense.)
- While asleep (sensor says nobody's near), frames are not run through face detection.
- Every integration receives only anonymous counts or fixed text, and has a test proving it:
  - Tiger Data / Snowflake: exactly `{machine_id, bay, event, ts}`. Never add fields.
  - Solana: restock `{machine_id, date, bay, restocked_qty}` and daily total `{machine_id, date, dispensed_total}`; integer counts only; devnet only.
  - Gemini: `aggregate_snapshot()` only (items left, per-hour counts, unique today).
  - ElevenLabs: the fixed `LINES` only; `voice.say()` takes a line name, never text.

## Rules for integrations

- Keys come from `.env` (placeholders in `.env.example`). With no key: log it and fall back; the demo must never break.
- Never block the camera loop: network calls run on background threads or subprocesses.
- Each has a `--no-<name>` flag in `main.py`.

## APIs the pages depend on

```
GET /state -> { "state": "sleep" | "idle" | "scanning" | "dispensed" | "already_served", "progress": 0-1, "item": ... }
GET /stats -> { "bays": [{ "name", "remaining", "capacity" }], "dispensed_today", "unique_today", "jam" }
GET /insights -> { "text", "source": "gemini" | "rules", "generated_at" }
fleet API: GET /fleet, /forecast, /ledger (dashboard takes ?fleet=<url>)
```
